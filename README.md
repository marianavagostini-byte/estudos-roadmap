# Estudos Roadmap

Personal study tracker and learning roadmap built with plain HTML, CSS and JavaScript. The pages are in Portuguese.

**Live site:** https://marianavagostini-byte.github.io/Estudos-Roadmap/

## What's inside

| File | What it is |
|---|---|
| `index.html` | Landing page linking the two tools below |
| `dojo-estudos.html` | Study progress page: topics in order, progress per track, streak and spaced review. Progress is saved in the browser with `localStorage` |
| `onde-estudar.html` | The roadmap split into phases, with completion criteria, dependencies and study sources for each topic |
| `SQL/pratica-01.sql` | SQL practice: `SELECT`, `WHERE`, `ORDER BY`, aggregate functions, `GROUP BY` and `HAVING` |

## Running locally

No build step or dependencies: open `index.html` in a browser, or serve the folder with any static server.
